PHẦN IV · PHOTON PUN 2

Ví dụ thực hành: Game nhiều người chơi đơn giản bằng PUN 2

Chương này tổng hợp toàn bộ kiến thức Phần IV (chương 20–24) thành một ví dụ hoàn chỉnh: mỗi người chơi điều khiển một quả cầu di chuyển tự do trong một arena nhỏ, nhìn thấy vị trí và tên hiển thị của những người chơi khác theo thời gian thực. Sau ví dụ code, chương khép lại Phần IV bằng bảng liệt kê những hạn chế cần cân nhắc khi đưa PUN vào sản phẩm thật, và gợi ý thời điểm nên chuyển sang Photon Fusion 2.

Cấu trúc scene Unity tối thiểu

Trước khi xem code, cần chuẩn bị đúng cấu trúc scene và prefab sau trong Unity Editor:

Code đầy đủ: GameManager (kết nối + spawn)

Photon C# GameManager.cs
using Photon.Pun;
using Photon.Realtime;
using Hashtable = ExitGames.Client.Photon.Hashtable;
using UnityEngine;

public class GameManager : MonoBehaviourPunCallbacks
{
    [SerializeField] private string playerPrefabName = "PlayerBall";

    void Start()
    {
        PhotonNetwork.GameVersion = "1.0";
        PhotonNetwork.NickName = "Player" + Random.Range(1000, 9999);
        PhotonNetwork.ConnectUsingSettings();
    }

    public override void OnConnectedToMaster()
    {
        PhotonNetwork.JoinRandomRoom();
    }

    public override void OnJoinRandomFailed(short returnCode, string message)
    {
        RoomOptions options = new RoomOptions { MaxPlayers = 8 };
        PhotonNetwork.CreateRoom("ArenaChinh", options);
    }

    public override void OnJoinedRoom()
    {
        // Spawn dong: PhotonNetwork.Instantiate tu dong gan PhotonView voi
        // Owner la chinh client nay (chuong 22)
        Vector3 spawnPos = new Vector3(Random.Range(-4f, 4f), 1f, Random.Range(-4f, 4f));
        GameObject myBall = PhotonNetwork.Instantiate(playerPrefabName, spawnPos, Quaternion.identity);

        // Gan ten hien thi qua Custom Properties (chuong 24) de moi client
        // - ke ca nguoi join sau - deu thay dung ten
        Hashtable props = new Hashtable { { "DisplayName", PhotonNetwork.NickName } };
        PhotonNetwork.LocalPlayer.SetCustomProperties(props);
    }

    public override void OnPlayerEnteredRoom(Player newPlayer)
    {
        Debug.Log(newPlayer.NickName + " da vao Arena.");
    }

    public override void OnPlayerLeftRoom(Player otherPlayer)
    {
        Debug.Log(otherPlayer.NickName + " da roi Arena.");
    }
}

Code đầy đủ: PlayerMovement (chỉ input nếu IsMine)

Photon C# PlayerMovement.cs
using Photon.Pun;
using UnityEngine;

[RequireComponent(typeof(Rigidbody))]
public class PlayerMovement : MonoBehaviourPun
{
    public float speed = 8f;
    private Rigidbody rb;

    void Awake()
    {
        rb = GetComponent<Rigidbody>();
    }

    void FixedUpdate()
    {
        // Quy tac song con cua moi script gameplay trong PUN (chuong 22):
        // KHONG xu ly input/vat ly neu day khong phai qua cau cua chinh minh
        if (!photonView.IsMine) return;

        float h = Input.GetAxis("Horizontal");
        float v = Input.GetAxis("Vertical");
        Vector3 force = new Vector3(h, 0, v) * speed;
        rb.AddForce(force);
    }
}

Code đầy đủ: PlayerSync (đồng bộ vị trí + tên hiển thị)

Photon C# PlayerSync.cs
using Photon.Pun;
using UnityEngine;
using TMPro;

public class PlayerSync : MonoBehaviourPun, IPunObservable
{
    [SerializeField] private TextMeshPro nameLabel;

    private Vector3 networkPosition;

    void Start()
    {
        // Doc Custom Properties da duoc dat o GameManager.OnJoinedRoom() (chuong 24)
        if (photonView.Owner != null &&
            photonView.Owner.CustomProperties.TryGetValue("DisplayName", out object nameObj))
        {
            nameLabel.text = (string)nameObj;
        }
        networkPosition = transform.position;
    }

    public void OnPhotonSerializeView(PhotonStream stream, PhotonMessageInfo info)
    {
        if (stream.IsWriting)
        {
            // May Owner: GUI vi tri hien tai di, dung mot thu tu co dinh (chuong 23)
            stream.SendNext(transform.position);
        }
        else
        {
            // May khac: NHAN vi tri ve, dung DUNG THU TU nhu luc gui
            networkPosition = (Vector3)stream.ReceiveNext();
        }
    }

    void Update()
    {
        if (photonView.IsMine) return;

        // Noi suy muot ma cho cac qua cau KHONG phai cua minh (chuong 6 + 23)
        transform.position = Vector3.Lerp(transform.position, networkPosition, Time.deltaTime * 10f);
    }
}
Ghi chú về TextMeshPro: Ví dụ trên dùng TextMeshPro (gói UI văn bản phổ biến đi kèm sẵn trong Unity) để hiển thị tên phía trên đầu quả cầu — có thể thay bằng TextMesh cơ bản hoặc một Canvas World Space tùy sở thích, không ảnh hưởng tới phần logic mạng.

Chạy thử: kiểm tra multiplayer cục bộ

Cách kiểm thử nhanh nhất không cần nhiều máy: build một bản .exe (File → Build Settings → Build), chạy song song bản build đó cùng lúc với chạy trực tiếp trong Unity Editor (Play). Cả hai đều kết nối tới cùng Photon Cloud, cùng App ID, nên sẽ tự động join chung một Room (do cùng dùng tên Room cố định "ArenaChinh" trong ví dụ), cho phép quan sát trực tiếp một quả cầu di chuyển mượt trên máy điều khiển nó và di chuyển nội suy trên "máy quan sát".

Khi nào nên cân nhắc chuyển sang Photon Fusion 2 hoặc middleware khác

Nên cân nhắc chuyển đổi khi: game của bạn bắt đầu cần tính cạnh tranh công bằng cao hơn (ranked, giải đấu), cần một mô hình có server thật sự có thẩm quyền để chống gian lận nghiêm ngặt hơn, hoặc cần một kiến trúc netcode hiện đại hơn với client-side prediction/reconciliation có sẵn (đã học lý thuyết ở chương 5). Đây chính xác là những gì Photon Fusion 2 — sản phẩm thế hệ mới hơn của cùng Exit Games — được thiết kế để giải quyết, với khả năng chạy ở cả chế độ tương tự PUN (Host/Client, dễ chuyển đổi) lẫn chế độ Server Mode có thẩm quyền thật. Phần V (chương 26 trở đi) sẽ trình bày đầy đủ Photon Fusion 2, bắt đầu bằng khái niệm nền tảng khác biệt lớn nhất so với PUN: Tick-based Simulation.
