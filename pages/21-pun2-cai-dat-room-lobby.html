PHẦN IV · PHOTON PUN 2

PUN 2: Cài đặt, Room & Lobby

Chương 20 đã giải thích PUN 2 (Photon Unity Networking 2) dựa trên hạ tầng relay Photon Cloud như thế nào. Chương này bắt đầu thực hành: cài đặt PUN 2 vào một project Unity, lấy App ID từ Photon Dashboard, kết nối tới Photon Cloud, rồi làm việc với hai khái niệm nền tảng đầu tiên của mọi trò chơi dùng PUN — Lobby (nơi liệt kê các phòng đang mở) và Room (một phiên chơi cụ thể). Kết thúc chương là một ví dụ code C# hoàn chỉnh: kết nối, tự động join-or-create một room, và log lại khi có người vào/ra.

Cài đặt PUN 2 vào project Unity

PUN 2 có thể được thêm vào một project Unity theo hai cách phổ biến:

  • Unity Asset Store: tìm gói "Photon PUN 2 - FREE" trên Asset Store, mở Package Manager trong Unity (Window → Package Manager → My Assets), tải và Import vào project. Đây là cách phổ biến nhất và được Exit Games khuyến nghị cho người mới.
  • Import trực tiếp file .unitypackage: tải file .unitypackage từ trang Photon Engine rồi Import thủ công qua menu Assets → Import Package → Custom Package.

Sau khi Import xong, một cửa sổ PUN Setup Wizard sẽ tự động hiện ra, yêu cầu nhập App ID — đây chính là bước tiếp theo.

Photon Dashboard & App ID

Photon App ID

Ý nghĩa: App ID là một chuỗi định danh duy nhất (dạng GUID) mà Exit Games cấp cho từng ứng dụng đăng ký trên Photon Dashboard (địa chỉ dashboard.photonengine.com). App ID đóng vai trò "chìa khóa" — mọi client dùng cùng một App ID sẽ được Photon Cloud coi là thuộc cùng một ứng dụng, và chỉ những client đó mới có thể thấy Room/Lobby của nhau. Nếu hai ứng dụng khác nhau dùng hai App ID khác nhau, chúng hoàn toàn tách biệt dù cùng chạy trên Photon Cloud.

Bước lấy App IDMô tả
1Đăng ký tài khoản miễn phí tại dashboard.photonengine.com
2Tạo một ứng dụng mới, chọn loại "Photon PUN" (khác với loại "Photon Fusion" dùng ở Phần V, hoặc "Photon Realtime" dùng cho các SDK tùy biến sâu hơn)
3Sao chép chuỗi App ID được cấp, dán vào ô "App Id PUN" trong PUN Setup Wizard của Unity (hoặc vào asset PhotonServerSettings nằm trong thư mục Assets/Photon/PhotonUnityNetworking/Resources)
Ghi chú: App ID không phải thông tin bí mật ở mức tuyệt đối như mật khẩu, nhưng vẫn không nên public tùy tiện trên các kho mã nguồn công khai — vì bất kỳ ai có App ID đều có thể kết nối vào ứng dụng của bạn và tiêu tốn hạn mức CCU miễn phí (chương 20) mà bạn không kiểm soát được.

Kết nối tới Photon Cloud

Photon PhotonNetwork.ConnectUsingSettings()

public static bool ConnectUsingSettings()

Ý nghĩa: Hàm khởi tạo kết nối tới Photon Cloud, sử dụng toàn bộ cấu hình đã được lưu sẵn trong asset PhotonServerSettings (App ID, region cố định hoặc chế độ tự chọn region tốt nhất, phiên bản ứng dụng...). Đây gần như luôn là dòng lệnh đầu tiên gọi tới PUN trong bất kỳ project nào — trước khi có thể join Lobby hay Room, client bắt buộc phải kết nối thành công tới Master Server của Photon (một máy chủ trung gian làm nhiệm vụ điều phối, khác với các relay server thực sự chuyển tiếp gói tin gameplay).

Giá trị trả về: true nếu yêu cầu kết nối được gửi đi hợp lệ (không đồng nghĩa đã kết nối thành công — kết nối là một quá trình bất đồng bộ, kết quả thật sự báo qua callback bên dưới); false nếu thiếu cấu hình bắt buộc (ví dụ App ID rỗng).

Khi nào dùng: Gọi trong Start() hoặc Awake() của một script quản lý kết nối (thường đặt tên NetworkManager/ConnectionManager), thường chỉ nên gọi một lần khi ứng dụng khởi động hoặc khi người chơi bấm nút "Play" ở màn hình menu chính.

Photon MonoBehaviourPunCallbacks

Ý nghĩa: Một lớp cơ sở (base class) do PUN 2 cung cấp, kế thừa từ MonoBehaviour thông thường của Unity, đồng thời triển khai sẵn hàng loạt interface callback của Photon. Thay vì phải tự implement nhiều interface (IConnectionCallbacks, IMatchmakingCallbacks, IInRoomCallbacks...) với đầy đủ mọi phương thức, script chỉ cần kế thừa MonoBehaviourPunCallbacks rồi override đúng những callback mình cần quan tâm — các callback không override sẽ dùng cài đặt mặc định (rỗng) sẵn có.

C# Khai báo script kế thừa MonoBehaviourPunCallbacks
using Photon.Pun;
using Photon.Realtime;
using UnityEngine;

public class NetworkManager : MonoBehaviourPunCallbacks
{
    void Start()
    {
        PhotonNetwork.ConnectUsingSettings();
    }
}

Photon OnConnectedToMaster()

public override void OnConnectedToMaster()

Ý nghĩa: Callback được PUN tự động gọi khi client đã kết nối thành công tới Master Server của Photon Cloud — tức đã sẵn sàng để gọi tiếp JoinLobby() hoặc trực tiếp tạo/tham gia Room. Đây là điểm khởi đầu hợp lệ đầu tiên để bắt đầu logic matchmaking.

Khi nào dùng: Trong hầu hết ví dụ đơn giản (kể cả ví dụ cuối chương này), có thể bỏ qua bước join Lobby tường minh và gọi thẳng JoinRandomRoom()/CreateRoom() ngay trong callback này.

Photon OnDisconnected(DisconnectCause cause)

public override void OnDisconnected(DisconnectCause cause)

Ý nghĩa: Callback được gọi khi client bị ngắt kết nối khỏi Photon Cloud, dù là do chủ động gọi PhotonNetwork.Disconnect(), do mất mạng, hay do server chủ động đóng kết nối. Tham số cause (kiểu enum DisconnectCause) cho biết lý do cụ thể, ví dụ DisconnectCause.ExceptionOnConnect, DisconnectCause.ServerTimeout, DisconnectCause.DisconnectByClientLogic...

Khi nào dùng: Luôn nên override để hiển thị thông báo phù hợp cho người chơi (ví dụ "Mất kết nối, đang thử kết nối lại...") thay vì để giao diện "đứng hình" không phản hồi khi mạng có vấn đề.

Lobby: danh sách các Room đang mở

Lobby là một khái niệm điều phối nằm giữa việc kết nối thành công tới Master Server và việc thực sự vào một Room để chơi — nó không phải là nơi diễn ra gameplay, mà chỉ là nơi liệt kê các Room đang mở, còn chỗ trống, mà client có thể chọn tham gia.

Photon PhotonNetwork.JoinLobby()

public static bool JoinLobby()
public static bool JoinLobby(TypedLobby lobby)

Ý nghĩa: Yêu cầu tham gia vào một Lobby cụ thể (hoặc Lobby mặc định nếu không truyền tham số) để bắt đầu nhận danh sách Room theo thời gian thực. Không bắt buộc phải join Lobby trước khi tạo/tham gia Room — nhiều game đơn giản (kể cả ví dụ trong tài liệu này) bỏ qua bước này và dùng thẳng JoinRandomRoom(), chỉ cần Lobby khi ứng dụng cần hiển thị cho người chơi một danh sách phòng để tự chọn (ví dụ danh sách bàn chơi trong game bài).

Photon OnRoomListUpdate(List<RoomInfo> roomList)

public override void OnRoomListUpdate(List<RoomInfo> roomList)

Ý nghĩa: Callback được gọi mỗi khi danh sách Room trong Lobby hiện tại có thay đổi (có phòng mới mở, phòng cũ đầy/đóng...). Tham số roomList chứa thông tin tóm tắt (tên phòng, số người hiện tại, số người tối đa...) của từng Room đang mở, dùng để hiển thị lên giao diện danh sách phòng cho người chơi lựa chọn.

Room: một phiên chơi cụ thể

Room (phòng) tương đương với khái niệm "một trận đấu" hay "một phòng chơi" — bên trong một Room, tất cả người chơi trao đổi dữ liệu gameplay với nhau qua relay của Photon Cloud (chương 20). Có ba cách phổ biến để vào một Room:

Photon PhotonNetwork.CreateRoom()

public static bool CreateRoom(string roomName, RoomOptions roomOptions = null, TypedLobby typedLobby = null)

Ý nghĩa: Tạo một Room mới với tên chỉ định. Nếu đã tồn tại một Room khác trùng tên, thao tác thất bại (callback OnCreateRoomFailed() được gọi).

Tham sốÝ nghĩa
roomNameTên định danh duy nhất của Room trong toàn ứng dụng; có thể để rỗng để Photon tự sinh một tên ngẫu nhiên
roomOptionsĐối tượng RoomOptions chứa các tùy chỉnh — chi tiết bảng bên dưới

Các trường quan trọng của RoomOptions:

TrườngÝ nghĩa
MaxPlayersSố người chơi tối đa được phép vào Room (0 = không giới hạn theo cấu hình phần mềm, nhưng vẫn bị giới hạn kỹ thuật của Photon)
IsVisibletrue = Room xuất hiện trong danh sách Lobby (OnRoomListUpdate); false = Room ẩn, chỉ vào được bằng đúng tên qua JoinRoom() (thường dùng cho phòng riêng tư/có mật khẩu)
IsOpentrue = còn nhận người chơi mới; đặt false để "khóa" Room lại giữa chừng (ví dụ trận đấu đã bắt đầu, không cho vào giữa chừng)
CustomRoomPropertiesHashtable chứa dữ liệu tùy chỉnh gắn với Room (chi tiết đầy đủ ở chương 24)

Photon PhotonNetwork.JoinRoom()

public static bool JoinRoom(string roomName)

Ý nghĩa: Tham gia một Room đã tồn tại, biết trước tên chính xác. Thất bại nếu Room không tồn tại, đã đầy, hoặc đã đóng (IsOpen = false) — báo qua callback OnJoinRoomFailed().

Photon PhotonNetwork.JoinRandomRoom()

public static bool JoinRandomRoom()

Ý nghĩa: Yêu cầu Photon tự tìm một Room ngẫu nhiên còn chỗ trống trong ứng dụng, không cần biết trước tên. Đây là cách phổ biến nhất để hiện thực "quick play" — người chơi bấm một nút duy nhất và được ghép ngay vào một trận đang chờ người.

Photon OnJoinRandomFailed(short returnCode, string message)

public override void OnJoinRandomFailed(short returnCode, string message)

Ý nghĩa: Callback được gọi khi JoinRandomRoom() thất bại — nguyên nhân phổ biến nhất không phải lỗi hệ thống mà đơn giản là hiện không có Room nào phù hợp đang mở (ví dụ chưa ai tạo phòng, hoặc mọi phòng đang mở đều đã đầy). Mẫu hình xử lý kinh điển và cực kỳ phổ biến trong PUN gọi là "Join or Create": ngay khi callback này được gọi, lập tức gọi CreateRoom() để tự tạo một phòng mới — nghĩa là người chơi đầu tiên bấm "Play" sẽ tự động trở thành người tạo phòng (và mặc nhiên trở thành Master Client, xem chương 24), còn người chơi tiếp theo bấm "Play" sẽ được ghép luôn vào phòng đó qua JoinRandomRoom() thành công.

sequenceDiagram participant C as Client participant M as Photon Master Server C->>M: ConnectUsingSettings() M-->>C: OnConnectedToMaster() C->>M: JoinRandomRoom() alt Co phong dang mo con cho M-->>C: OnJoinedRoom() else Khong co phong nao phu hop M-->>C: OnJoinRandomFailed() C->>M: CreateRoom(ten_phong) M-->>C: OnJoinedRoom() end

Vòng đời của một Room: các callback quan trọng

Photon Các callback vòng đời Room

CallbackKhi nào được gọi
OnJoinedRoom()Client (bao gồm cả trường hợp vừa tạo phòng) đã chính thức ở trong Room, có thể bắt đầu spawn player, đọc danh sách người chơi hiện có qua PhotonNetwork.PlayerList

Ví dụ code đầy đủ: kết nối, join-or-create Room, log vào/ra

Photon C# NetworkManager.cs — kết nối và join-or-create một room cố định
using Photon.Pun;
using Photon.Realtime;
using UnityEngine;

// Gan script nay len mot GameObject duy nhat trong scene menu/khoi dong
public class NetworkManager : MonoBehaviourPunCallbacks
{
    private const string RoomName = "PhongChoiChinh";
    private const int MaxPlayersPerRoom = 4;

    void Start()
    {
        Debug.Log("Dang ket noi toi Photon Cloud...");
        // Dam bao moi client dung chung phien ban de tranh ghep nham
        // giua cac ban build khong tuong thich
        PhotonNetwork.GameVersion = "1.0";
        PhotonNetwork.ConnectUsingSettings();
    }

    public override void OnConnectedToMaster()
    {
        Debug.Log("Da ket noi Master Server. Dang tim phong...");
        PhotonNetwork.JoinRandomRoom();
    }

    public override void OnDisconnected(DisconnectCause cause)
    {
        Debug.LogWarning("Mat ket noi Photon, ly do: " + cause);
        // Co the hien UI thong bao va cho phep nguoi choi bam "Ket noi lai"
    }

    public override void OnJoinRandomFailed(short returnCode, string message)
    {
        Debug.Log("Khong tim thay phong phu hop, dang tao phong moi...");
        RoomOptions options = new RoomOptions
        {
            MaxPlayers = MaxPlayersPerRoom,
            IsVisible = true,
            IsOpen = true
        };
        PhotonNetwork.CreateRoom(RoomName, options);
    }

    public override void OnJoinedRoom()
    {
        Debug.Log(string.Format(
            "Da vao phong '{0}'. So nguoi hien tai: {1}/{2}",
            PhotonNetwork.CurrentRoom.Name,
            PhotonNetwork.CurrentRoom.PlayerCount,
            PhotonNetwork.CurrentRoom.MaxPlayers));

        // Tu day co the goi PhotonNetwork.Instantiate() de spawn player (chuong 22)
    }

    public override void OnPlayerEnteredRoom(Player newPlayer)
    {
        Debug.Log("Nguoi choi moi vao phong: " + newPlayer.NickName);
    }

    public override void OnPlayerLeftRoom(Player otherPlayer)
    {
        Debug.Log("Nguoi choi da roi phong: " + otherPlayer.NickName);
    }

    public override void OnLeftRoom()
    {
        Debug.Log("Ban da roi khoi phong.");
    }
}
Lưu ý: Trước khi có thể tạo/tham gia Room, PUN yêu cầu client phải đặt một NickName (tên hiển thị) — nếu không đặt, mặc định sẽ rỗng và gây khó khăn khi hiển thị danh sách người chơi. Nên đặt PhotonNetwork.NickName = "TenNguoiChoi"; trước hoặc ngay sau khi gọi ConnectUsingSettings(). Ngoài ra, cần kiểm tra PhotonNetwork.IsConnected trước khi gọi các hàm join/create nếu chúng được kích hoạt từ một nút bấm UI — gọi khi chưa kết nối xong sẽ khiến hàm trả về thất bại ngay lập tức.

Chương 22 sẽ đi vào phần quan trọng tiếp theo: làm sao thực sự spawn nhân vật người chơi vào Room vừa tạo/tham gia này, và khái niệm cốt lõi Ownership quyết định ai được phép điều khiển đối tượng nào trên mạng.
